¿Cómo funciona? ¿Es seguro?

Tu API key y tu archivo nunca salen de tu navegador — las descripciones se envían directamente a Groq para clasificarse y el resultado se arma aquí mismo. No hay servidor intermedio. La key se guarda localmente para que no la escribas cada vez.

El sistema entiende el contexto: detecta negaciones ("auriculares no incluidos"), accesorios incluidos, y referencias de marca. Si una fila falla (por límite de Groq), queda marcada y puedes reintentar solo esas con el botón.

Las reglas personalizadas que escribas se guardan en tu navegador y se aplican a cada clasificación — úsalas para corregir errores que veas seguido (marcas, categorías especiales, etc.).
